# Two Futures artwork

Put the two Adobe Firefly images here, with exactly these names:

- `future-buy.webp`: "If you buy it."
- `future-wait.webp`: "If you wait."

Portrait or near-square works best (they are cropped to fill, centred). About 1600 px on the long side is plenty.

If a file is missing, the app shows a plain typographic panel for that side and drops the Firefly credit. See `docs/ADOBE_FIREFLY.md`.
