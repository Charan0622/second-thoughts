# Test users (fictional)

Two invented people for trying Second Thoughts as a **new user**, not the Maya demo:

- `jordan/`: Jordan Lee, a tight month (≈ $239 free before payday), building an emergency fund.
- `priya/`: Priya Nair, comfortable (≈ $2,158 free), saving for a car.

Each folder has a bank statement, a pay stub, receipts in several formats (email, photo, PDF, text) and `ANSWERS.md` with what to type in the quick questions. `products/` has photos to check, including one with no price tag. Regenerate with `uv run --project backend python scripts/gen_test_users.py`. All data is invented.
